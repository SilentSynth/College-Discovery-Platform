# 🎓 College Discovery Platform

A frontend MVP for a college discovery and decision-making platform. Built to simplify the process of finding, comparing, and shortlisting engineering colleges. 

This is a mock platform focused on clean UI architecture, responsive design, and state management, providing a fast and seamless user experience similar to production-level ed-tech portals.

## 🌐 Live Preview

Check out the live deployment here: **[Live Site](https://college-discovery-platform-ashen-five.vercel.app/)**

## ✨ Core Features

* **Smart Discovery:** Browse a mock dataset of top colleges. Filter results dynamically by location, tuition fees, and minimum ratings.
* **Side-by-Side Comparison:** A persistent, interactive "Compare Tray" that lets users select up to 3 colleges and view their metrics side-by-side.
* **College Predictor:** Input an exam type and rank to get immediate, logic-driven college recommendations.
* **Detailed Analytics:** College detail pages feature interactive line charts tracking historical placement and fee trends.
* **System-Wide Dark Mode:** Fully persistent light/dark mode toggling.

## 🛠️ Tech Stack

* **Framework:** React + Vite
* **Styling:** Tailwind CSS
* **Data Visualization:** Recharts
* **Deployment:** Vercel

## 🚀 Running Locally

If you want to pull this down and run it on your own machine, run the following commands in your terminal:

```bash
# 1. Clone the repository
git clone [https://github.com/SilentSynth/College-Discovery-Platform.git](https://github.com/SilentSynth/College-Discovery-Platform.git)

# 2. Navigate into the directory
cd College-Discovery-Platform

# 3. Install the dependencies
npm install

# 4. Start the development server
npm run dev
